# Ruleset v1 — the standard competition format

**Status:** proposed — awaiting David's ratification. Nothing depends on this
format until it is ratified.
**Date:** 2026-07-04
**Author:** coder dispatch `M-foedus-ruleset-v1`
**Evidence:** `docs/design/2026-07-04-ruleset-v1-evidence/` (raw `results.json`
+ three figures) — reproduce with `scripts/foedus_ruleset_eval.py`.
**Preset:** `foedus.presets.ruleset_v1` (this PR).

---

## 0. TL;DR — the proposed format

Foedus is becoming a public arena + training gym. Every future experiment and
match should run in **one** standard format so results accumulate on a single
ladder. This doc designs that format and validates the *board* parameters
empirically with cheap heuristic sweeps (no LLM spend).

| Knob | v1 value | One-line justification (evidence §) |
|---|---|---|
| **Seats** | **4** | Highest skill discrimination on the standard map; lowest elimination-variance; simplest coalition math (§6.2). |
| **Turns** | **12** | Discrimination saturates by turn 8 (§6.3); 12 is the *shortest* length that keeps the détente/alliance win condition live (§7.3), for +50% cost over 8 but no wasted turns like 15. |
| **Map radius** | **2** (19 hexes) | Decisive: radius 2 recovers the true skill ladder perfectly (Kendall τ = 1.00); radius 1 (7 hexes) is elimination-dominated and cannot (τ ≈ 0) (§6.1). |
| **Archetype** | **continental_sweep** | Dense connectivity; scarcity (not chokepoints) drives contact — the playtest/conflict-preset choice. |
| **Détente threshold** | **engine default `4 + num_players`** (= 8 at 4 seats) | Unchanged. Live at 12 turns (window turns 8–12); scales with table size; heuristic sweeps show it is neither trivial (~0% for a skill field) nor forced (§7.3). |
| **Reciprocation ledger** | **ON** | Entrant baseline scaffold (PR #36); engine default. |
| **Campaign memory** | **ON** | Recurring opponents are the point of a ladder (PR #38). |
| **Retreats** | **OFF** | v1 lethality (retreats-evidence packet default). |
| **CLI timeout** | **300 s / decision** | Matches the crossgame-memory default bump; headroom for slow LLM seats. |
| **Games per match** | **8** (two 4-seat rotation cycles) | A match is a *provisional* read; the **persistent** cross-match ladder does the heavy convergence (~40 clean-field games ≈ 5 matches) (§6.5, §7.6). |
| **Seat rotation** | **cyclic Latin square** over the 4 seats | Each entrant occupies each seat position an equal number of times (§7.4). |
| **Seeds** | **commit-reveal** (publish SHA-256 of the seed list *before*, reveal *after*) | Anti-cheat for a public arena (§7.5). |
| **Roster** | **4 entrants**, or **3 entrants + 1 house anchor** | House anchor = fixed-skill calibration seat that ties the global ladder together (§7.7). |
| **Rating** | **OpenSkill (Plackett-Luce), per game**, **unique identity per entrant** | Conservative `μ − 3σ` for standings (§7.8). |

**Per-entrant cost of one match (recommended format):** ~8 games × ~72
LLM decisions/game ≈ **~580 calls ≈ ~9–10 h sequential** at ~1 min/decision
(§7.9).

## 1. Purpose and scope

**In scope (this doc decides):** the board parameters (seats / turns / radius /
archetype), the standard toggles, the match structure (games-per-match, seat
rotation, sealed seeds), roster composition, and the rating protocol — plus the
empirical evidence for the parameters that could be measured cheaply.

**Explicitly out of scope:** the leaderboard/web productization, a matchmaking
service, entrant-onboarding docs, the rating-identity and resolver fixes owned
by a parallel coder (`foedus/rating.py`, `foedus/resolve.py` are untouched
here), and any large LLM-seat experiment. This design *assumes* unique rating
identities (the duplicate-identity fix lands separately).

**Method in one sentence:** run a fixed heuristic skill ladder through every
candidate format with the cheap sim harness (10k games ≈ 40 s, zero LLM
calls) and let pre-registered metrics pick the parameters.

## 2. The skill ladder (calibration)

Discrimination can only be *measured* against a field of known, graduated skill.
A 4000-game calibration at the base format (4 seats / 12 turns / radius 2) over
12 candidate heuristics produced a clean, monotonic six-rung ladder. The tied
top cluster (Bandwagon / GreedyHold / TitForTat all emit GreedyHold orders — μ
within 1.7, a statistical tie) is represented by the required freerider probe
**DishonestCooperator** alone, so no two rungs are a tie by construction.

| Rung | Heuristic | μ (calib.) | mean rank | win-rate | role |
|---|---|---|---|---|---|
| 6 (strong) | **DishonestCooperator** | 35.97 | 1.685 | 52.7% | required freerider probe |
| 5 | Aggressive | 29.44 | 2.122 | 29.5% | mid-high |
| 4 | Greedy | 25.25 | 2.434 | 14.4% | mid |
| 3 | Sycophant | 23.08 | 2.514 | 15.3% | mid-low (≈ tied with Greedy) |
| 2 | Random | 20.31 | 2.812 | 8.2% | weak |
| 1 (floor) | Defensive | 8.22 | 3.307 | 0.0% | do-nothing floor |

The graduated gaps are deliberate: two wide (top and bottom) and three
tight in the middle (Greedy↔Sycophant is only ~2.2 μ). Wide gaps test that a
format separates *obvious* skill; the tight middle pair tests how much data it
takes to separate *close* skill — which turns out to be the crux of the
games-per-match question (§6.5). The ladder is defined in
`foedus/eval/ruleset.py:LADDER`.

## 3. Pre-registered selection criteria

These metrics and thresholds were encoded in `foedus/eval/ruleset.py` and
committed **before** the full grid was run (git: the harness commit precedes the
evidence commit). The numbers, not taste, pick the format.

- **Recovery fidelity τ** — Kendall τ between a format's asymptotic OpenSkill
  ordering and the true ladder. A format is *valid* only if **τ ≥ 0.9**
  (it must measure the skill we think it does). **This is the gate.**
- **Discrimination index D** = `stdev(μ) / mean(σ)` across the six rungs — a
  signal-to-noise ratio. Higher = the ladder is separated more cleanly.
  *Only meaningful for formats that pass the τ gate* — D is the spread of
  whatever ordering the format produces, correct or not.
- **Adjacent separation** — how many of the five adjacent rungs are confidently
  distinguishable (μ gap > combined σ).
- **Convergence g95** — the smallest number of games after which the match
  standings sort the field correctly (τ ≥ 0.9) in **≥ 95 %** of shuffled
  game-order replays. Answers "games per match."
- **Health guards** — a format is *unhealthy* if détente fires so often it
  measures coordination not skill (**> 25 %**), or elimination is so high that
  games routinely collapse before they can express skill.

**Cost lenses.** Seats: D **per game**. Turns: D **per turn** (an LLM entrant
pays ~1 min per decision and ~1 decision per turn, so turns are the entrant's
cost driver). Radius: D per game, noting radius's marginal effect on prompt
size.

**Decision rule (pre-registered):** among τ-valid formats, take the
**seats × radius** with the highest D per game; then the **shortest** turn
length whose D is statistically indistinguishable from the best (don't pay for
turns that add no signal), unless a *game-integrity* constraint (a live détente
track) requires more.

## 4. Method

`scripts/foedus_ruleset_eval.py` reuses the engine's `run_one_game` (no game
logic is duplicated) and adds three phases:

1. **Format grid** — seats {4,5,6} × turns {8,12,15} × radius {1,2} = 18
   formats, **3000 games each**, distinct-seat sampling of the six-rung ladder.
   Per format: D, adjacent separation, recovery τ, détente rate, elimination
   rate, actual length.
2. **Convergence** — for representative match rosters, replay 800 games in 200
   shuffled orders and record P(standings sorted correctly) vs games.
3. **Détente sensitivity** — an ALLY-inclined roster across turn lengths, to
   separate the format's effect on détente from the (dominant) roster effect.

**Distinct-seat sampling** is the one methodological choice worth flagging: a
real match seats *distinct* entrants, so every seat carries a unique rating
identity. The stock sweep draws seats i.i.d. *with replacement* (two seats can
be the same heuristic → duplicate identities in one game — the exact case the
parallel rating-identity fix owns). Sampling without replacement models the
format we are actually designing and keeps this work off the duplicate-identity
path. Détente is run at the **engine-default** threshold (not disabled) so
détente rate is a real measurement.

All runs: `continental_sweep`, engine-default détente threshold, no LLM calls,
3000/800/1500 games per phase, ~90 s wall total on 12 cores.

## 6. What the evidence says

### 6.1 Map radius — decisive (radius 2)

This is the clearest result in the study. **Every radius-2 format recovers the
true ladder perfectly (τ = 1.00). No radius-1 format does** — radius-1 τ ranges
from +0.47 down to **−0.20** (at 6 seats / 15 turns the ordering is *worse than
random*). Radius 1 is a 7-hex disk; with 4–6 home bases packed into it, games
are elimination brawls (elim 24–48 %) whose outcome is dominated by starting
adjacency, not skill. Note the trap: radius-1's D at 6 seats (2.9) *looks*
respectable, but it is the spread of a scrambled ordering (τ ≈ 0) — which is
exactly why the τ gate exists. **Radius 2 is required.** (A radius-3 board — the
engine default, ~37 hexes — was out of the brief's 1-vs-2 scope; §9 flags it for
follow-up, since 6-seat crowding at radius 2 suggests larger boards may suit
larger tables.)

### 6.2 Seats — 4

Among the τ-valid (radius-2) formats, **discrimination falls monotonically as
seats rise**: D = 5.0 (4 seats) → 3.7 (5) → 3.3 (6) at 12 turns, and adjacent
separation drops from 3/5 to 1/5. The mechanism is crowding: on a fixed 19-hex
board, more seats means more forced contact and **elimination roughly doubles
per two seats** (10 % → 20 % → 32 % at 12 turns), and elimination is variance,
which drowns skill signal. Four seats also keeps the freerider/coalition social
layer legible — 4-way coalition math (who supports whom, 2-v-2 vs 3-v-1) is the
richest structure that is still analyzable; 5–6 seats multiply the
kingmaker/collusion surface without adding measured discrimination. **4 seats.**
(If a future format wants 5–6 seats for social richness, §6.1's radius-3
follow-up should come first so the board isn't the bottleneck.)

### 6.3 Turns — 12 (discrimination saturates at 8; détente needs the headroom)

**Discrimination is flat-to-declining in turns**: at 4 seats / radius 2,
D = 5.06 (t8) ≈ 4.98 (t12) ≈ 4.70 (t15), all at τ = 1.00. The ladder's skill is
fully expressed by turn 8; turns 9–15 add elimination variance (elim 4 % → 10 %
→ 15 %) and **entrant cost** (each turn ≈ one paid LLM decision) but **no skill
signal**. On the pure discrimination-per-turn lens, **8 turns wins.**

So why recommend 12? **Game integrity.** The détente/alliance victory — the
condition that names the project (*foedus* = treaty) — needs
`mutual_ally_streak ≥ detente_threshold` consecutive all-pairs-ALLY turns, and
`detente_threshold = 4 + num_players = 8` at 4 seats. In an **8-turn** game the
streak can only reach 8 by allying from turn 1 through turn 8 — détente can fire
*only on the final turn*, a degenerate non-choice. At **12 turns** the window is
turns 8–12: a live five-turn race-to-peace alternative to conquest. Twelve turns
buys a working alliance track for +50 % cost over 8; **15 turns buys nothing** the
discrimination numbers can see, for +25 % more cost than 12. **12 turns** is the
shortest length that is both fully discriminating *and* keeps the namesake
mechanic live.

> **Honest caveat.** "Turns add no signal past 8" is a *heuristic-layer* result;
> heuristics don't negotiate, so their skill is a turn-1 property. For LLM
> entrants, mid-game negotiation, betrayal timing, and the détente race may make
> later turns informative. 12 turns is the conservative choice that protects that
> possibility; an operator who only cares about conquest-skill discrimination at
> minimum cost could run 8 turns with détente off. Validating turn-length at the
> LLM layer is deferred (§9).

### 6.4 Détente and elimination by format

**Détente is a roster phenomenon, not a format one.** Across the *entire*
18-format grid the skill ladder produced détente **0.0 %** of the time — the
rungs don't coordinate all-pairs-ALLY. Swap in an ALLY-inclined roster
(Cooperator / TrustfulCooperator / DishonestCooperator / Sycophant) and détente
fires **66–82 %** (8/12/15 turns). So détente rate measures *how cooperative the
field is*, and turn length only nudges it. The C2 note of 10.34 % détente sits
between these poles — an LLM field that is *sometimes* cooperative — and is a
healthy, non-degenerate rate. **Implication:** détente-threshold tuning is an
*LLM-layer* question (deferred, §9); the heuristic sweeps show the default is
neither trivially reachable nor impossible, so v1 keeps it (§7.3).

**Elimination** *is* format-sensitive and behaves sensibly: it rises with seats
(crowding) and turns (more chances), and explodes at radius 1. At the
recommended 4/12/2 it is a moderate 9.9 % — games are decided by supply score,
not luck of a first-strike, which is what we want for a skill measure.

### 6.5 Rating convergence — "games per match" is about field *separation*, not seat count

See `fig1_convergence.png`. Modelling a match as a fixed set of recurring
entrants with seat rotation, replayed in 200 shuffled orders:

| Match field | g95 (≥95 % correctly sorted) | mean τ @ 800 games |
|---|---|---|
| 4 entrants, well-spread | **40** | +1.00 |
| 4 entrants, **incl. a near-tied pair** | **> 800** (0.61 @ 800) | +0.87 |
| 5 entrants, well-spread | ~800 (0.97 @ 800) | +0.99 |
| 6 entrants, full ladder (two near-ties) | **> 800** (0.41 @ 800) | +0.87 |

The disentangling result: a **4-entrant** field with one near-tied pair
converges **no better** than the 6-entrant field. Convergence is governed by how
*separated* the field is, not by the raw seat count. Two consequences:

- **The strict "sort every pair correctly" bar is unforgiving to genuine ties.**
  A coin-flip pair (Greedy↔Sycophant, ~2 μ apart) should *not* resolve without
  a lot of data — and arguably the ladder shouldn't pretend it can. **Mean τ
  stays 0.87–1.00 everywhere**: the *ordering* is essentially right long before
  the all-pairs bar saturates.
- **A single match cannot be sized to fully converge affordably.** 40 games is
  the *easy* case; realistic close fields want far more, and 40 games × ~72
  calls ≈ 1–2 days of LLM time per entrant. The answer is the **persistent
  ladder** (§7.6, §7.8): a match yields a *provisional* read (mean τ ≈ 0.9 by
  ~10–15 games; σ falling from 8.7 → ~4), and the unique persistent OpenSkill
  identity keeps refining across matches against recurring opponents. Clean-field
  convergence (~40 games) accrues over ~5 matches, which is exactly the
  campaign/ladder model (PR #38). Turn length barely moves convergence
  (4-spread g95 = 60 at 8 turns vs 40 at 12).

## 7. The format, specified

### 7.1 Board
`num_players = 4`, `max_turns = 12`, `map_radius = 2`,
`archetype = continental_sweep`, `build_period` = engine default.
Encoded in `foedus.presets.ruleset_v1`.

### 7.2 Ladder separation at the recommended format
`fig3_ladder.png`; 3000-game μ ± σ at 4/12/2:

| rung | μ | σ |
|---|---|---|
| DishonestCooperator | 38.11 | 1.74 |
| Aggressive | 31.69 | 1.67 |
| Greedy | 25.47 | 1.66 |
| Sycophant | 22.82 | 1.66 |
| Random | 21.44 | 1.67 |
| Defensive | 10.69 | 1.89 |

τ = 1.00, 3/5 adjacent pairs confidently separated (the two unseparated are the
deliberate near-ties). This is what a healthy, legible skill spectrum looks like.

### 7.3 Détente threshold — keep `4 + num_players`
Unchanged from the engine default (= 8 at 4 seats). Justification: (a) with
`max_turns = 12` it is *live* (window turns 8–12); (b) it scales correctly with
table size — a bigger table needs more turns of unanimous peace, which is the
right difficulty curve; (c) the heuristic sweeps bracket it as non-degenerate
(≈0 % for a competitive field, ≈70 % for pure cooperators), and the LLM-layer
observation (10.34 %) sits in the healthy middle. There is no cheap heuristic
evidence that would justify moving it; if it moves, that decision belongs to an
LLM-layer study (§9).

### 7.4 Seat rotation
Position/board asymmetry is real (home adjacency differs by seat), so entrants
must cycle through seats. **Scheme:** the four entrants of a match play a
**cyclic Latin square** — over any four consecutive games each entrant occupies
each of the four seat positions exactly once (game *k*: entrant *i* → seat
`(i + k) mod 4`). An 8-game match is two full cycles, giving perfectly balanced
seat exposure. The map seed varies per game (§7.5), so entrants also see a
spread of boards, not one board four ways.

### 7.5 Sealed seeds (commit-reveal) — anti-cheat for a public arena
Per-game map/seed determinism must not let an entrant pre-compute or recognize a
board. Protocol:
1. **Commit (before the match):** the operator draws the match's seed list
   `S = [s₁ … s_G]` (one per game) from a CSPRNG, computes
   `commit = SHA-256( "foedus-ruleset-v1|" + match_id + "|" + json(S) + "|" + nonce )`,
   and **publishes `commit` + `match_id`** (e.g. in the match record / on-chain
   of the leaderboard) *before any game is played*.
2. **Play:** games run on `S` in order, with the seat rotation of §7.4. Entrants
   never see `S` or `nonce`.
3. **Reveal (after the match):** the operator publishes `S` and `nonce`. Anyone
   can recompute the hash and confirm it matches `commit`, proving the seeds were
   fixed in advance and not cherry-picked to favor a result.

This binds the operator to the boards up front (they can't re-roll a seed that
gave a disliked result) and binds entrants (they can't have been shown the
seeds). `nonce` prevents brute-forcing the seed list from the hash; `match_id`
domain-separates commits. Seeds are the engine's existing `GameConfig.seed` —
no engine change is needed.

### 7.6 Games per match — 8, with the ladder doing the convergence
A match is a **campaign** of recurring opponents (PR #38 made cross-game memory
a measured axis). **v1 match = 8 games** = two seat-rotation cycles: perfectly
seat-balanced, and enough that mean τ ≈ 0.9 with σ well down from the prior. A
single match is deliberately *provisional*; §6.5 shows full convergence can't be
bought inside one affordable match, so the **persistent ladder** carries it.
A **4-game** (one-cycle) variant is offered for tight budgets. Do **not** size a
match at 40 games — that is ~1–2 days of LLM time per entrant (§7.9) for a
precision the persistent ladder reaches for free over ~5 matches.

### 7.7 Roster composition
**v1 default: 4 entrants**, all four seats filled by the match's four entrants.
Simplest thing that yields comparable ratings. **Calibration variant:
3 entrants + 1 house anchor** — a fixed-skill house agent (e.g. a
DishonestCooperator-class "boss") occupies one seat. The anchor is the same
identity in every match it appears in, so it ties otherwise-disjoint matches
onto a common scale (like a reference player in an Elo pool) and doubles as a
sanity boss. Recommendation: run the house anchor in a fraction of matches so the
global ladder stays commensurable even when entrant pools don't overlap.
Mixed-tier matchmaking is a later concern (out of scope).

### 7.8 Rating
OpenSkill (Plackett-Luce) via `foedus.rating.RatingSystem`, updated **once per
game** from the game's competition ranks (`foedus.scoring.compute_match_result`
conventions; ties share a rank, eliminated share the worst). **Unique identity
per entrant** — a persistent identity that accumulates across every game of every
match (this design assumes the duplicate-identity fix; it does not implement it).
Standings use the conservative `μ − 3σ` so a lucky newcomer can't leapfrog an
established entrant. Detached from press: rating consumes only final ranks, so it
is identical whether or not entrants negotiate.

### 7.9 Cost envelope
Per entrant, per game, at 4/12/2: ~12 turns × (≈1 negotiation + 1 orders
decision) ≈ **~24–72 paid LLM calls** (call it ~72 at the upper, press-heavy
bound; the brief's "~48 calls/game today" anchors the middle). At ~1 min/call:

| Match size | calls / entrant | wall-clock / entrant (sequential) |
|---|---|---|
| **8 games (v1)** | ~380–580 | **~6–10 h** |
| 4 games (budget) | ~190–290 | ~3–5 h |
| 40 games (full single-match convergence — *not recommended*) | ~1.9–2.9 k | ~32–48 h |

Turns are the dominant multiplier (cost ∝ turns), which is why §6.3 refuses to
pay for 15. Seats add *parallel* seat-cost per game but not per-entrant serial
cost. The persistent ladder (§7.6) is what makes the affordable 8-game match
sufficient.

## 8. Honest trade-off table (the calls that weren't free)

| Decision | Chosen | Runner-up | What we gave up | Why it's still right |
|---|---|---|---|---|
| Turns | 12 | **8** (cheaper, equal discrimination) | ~50 % lower entrant cost | 8 turns makes détente degenerate (fires only on the last turn); 12 keeps the namesake alliance track live. A conquest-only operator may prefer 8 + détente-off. |
| Seats | 4 | 5–6 (richer social layer) | more coalition/kingmaker structure | On radius 2, 5–6 seats measurably *lose* discrimination to crowding; fix the board (radius 3) before widening the table (§9). |
| Radius | 2 | (radius 1 rejected outright) | — | Radius 1 fails the τ gate; there was no trade-off, only a wrong answer. Radius 3 is a live follow-up for larger tables. |
| Games/match | 8 | 40 (fully converged) | single-match precision on near-tied fields | 40 games is 1–2 days/entrant; the persistent ladder reaches that precision over ~5 matches for free. |
| Détente threshold | default `4+n` | a tuned value | possible LLM-layer optimum | No cheap evidence justifies a specific new value; heuristic sweeps only bound it as healthy. Defer to an LLM study. |

## 9. What this pass did **not** settle (LLM-layer follow-ups)

- **Turn length at the LLM layer.** Heuristics express skill by turn 1; the
  "past turn 8 adds nothing" result may not hold once entrants negotiate. One
  cheap check: a single 1-game claude-cli smoke was **not** run because no
  recommended parameter changes prompt structure enough to warrant it (radius 2
  vs 3 would; we stayed at 2). Worth a small LLM turn-length A/B before v2.
- **Détente-threshold tuning** is inherently an LLM/press-layer question (§6.4).
- **Radius 3 for larger tables.** 5–6 seats lose discrimination to radius-2
  crowding; a radius-3 board may let bigger tables breathe. Out of the 1-vs-2
  brief; flagged for a follow-up sweep.
- **The duplicate-identity and resolver fixes** are owned by a parallel coder;
  this design assumes unique identities and does not touch `rating.py` /
  `resolve.py`.

## 11. The preset

```python
from foedus.presets import ruleset_v1
cfg = ruleset_v1(num_players=4, seed=42)   # the standard competition config
```

`ruleset_v1` returns the §7.1 `GameConfig`. Match-level structure (rotation,
seeds, games-per-match, roster, rating) is protocol layered *around* the engine
config, not fields on it — the engine stays a pure state-transition core
(architecture invariant). This preset is the single source of truth for the
board once ratified.
